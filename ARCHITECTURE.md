# Arquitectura LUMEN v183

La v183 es la primera entrega modular real. La modularización es física: HTML, CSS y JavaScript viven en archivos separados y el bootstrap ensambla la aplicación antes de ejecutar la lógica funcional.

## Regla de evolución

A partir de v183, las mejoras se realizan en el módulo responsable. No se reemplaza la aplicación completa para modificar una función aislada.

## Próximas etapas

- v184: schemaVersion, migraciones explícitas, health check y diagnóstico.
- v185: índices en memoria, dirty modules, render parcial y optimización de sync.
- v186: mejoras UX, incluyendo JSON bibliográfico desde Lectura en curso.
